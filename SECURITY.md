# Security

If you find a security problem in Comfort — for example a way for a link, a site or another app to
read your cookies or logins, run code, or reach files it shouldn't — please report it privately:

**[Report a vulnerability](https://github.com/d-gibr1l/comfort/security/advisories/new)**

Please don't open a public issue for it. Include what's affected, how to reproduce it, and the
Comfort version (Settings › About). You'll get a reply as soon as possible, and credit in the fix's
release notes if you'd like it.

Only the [latest release](https://github.com/d-gibr1l/comfort/releases/latest) gets security fixes.

Problems in yt-dlp, gallery-dl or Instaloader themselves belong to those projects; if you're not
sure where one belongs, report it here and it'll be passed on.
